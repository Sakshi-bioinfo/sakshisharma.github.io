A personal portfolio and scientific blog website built using Jekyll and GitHub Pages.

This website showcases my research journey, bioinformatics projects, publications, blogs, and academic work at the intersection of biology, machine learning, and computational genomics.

🔗 Live Website: https://sakshi-bioinfo.github.io/bioinfomaestro.github.io/

---

## About

BioinfoMaestro is my personal academic and professional website designed to:

- Present my research work and publications
- Share beginner-friendly bioinformatics blogs
- Showcase projects and technical skills
- Build a scientific online presence
- Document my journey in computational biology and AI-driven genomics

The website focuses on clean scientific aesthetics, responsive design, and accessible content for students and researchers.
